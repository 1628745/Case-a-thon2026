Run facts

Privacy

Your file is read by Python running inside this browser tab (Pyodide, WebAssembly). It is never uploaded; the page makes no network requests with your data and has no analytics. The only downloads are Pyodide and its packages from cdn.jsdelivr.net, D3 from cdnjs and the fonts.

Honesty rules

The Guard's settings are the frozen config.yaml guard block (tag guard-v1-frozen), never tuned on your file. Results are shown as they come out, including when the Guard doesn't help.
